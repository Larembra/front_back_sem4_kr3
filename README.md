# Контрольная работа №3 (Фронтенд и бекенд разработка)

Инструкция по запуску и отладке проекта локально (Windows, PowerShell).

План действий
- Установить зависимости
- Подготовить TLS-сертификаты (рекомендуется mkcert) или работать по HTTP на localhost
- Запустить сервер с нужными портами
- Открыть приложение в браузере и проверить регистрацию Service Worker / push

Требования
- Node.js (рекомендую 14+; у вас сейчас Node.js v24 работает)
- npm
- (опционально) mkcert для выдачи доверенных локальных сертификатов

Установка зависимостей
Откройте PowerShell в папке проекта и выполните:

```powershell
npm install
```

Генерация локальных сертификатов (рекомендуемый вариант — mkcert)
1) Установите настоящий mkcert (не npm-версию). Самый простой путь — скачать `mkcert.exe` с релизов:
   https://github.com/FiloSottile/mkcert/releases
   Положите `mkcert.exe` в папку и добавьте её в PATH или запускайте по полному пути.

2) Выпустите корневой сертификат и сертификат для localhost:

```powershell
mkcert -install
mkcert -key-file localhost+2-key.pem -cert-file localhost+2.pem localhost 127.0.0.1 ::1
```

Эти файлы (`localhost+2-key.pem` и `localhost+2.pem`) должны оказаться в корне проекта рядом с `server.js`.

Если вы не хотите (или не можете) использовать mkcert, сервер автоматически запустится по HTTP, если не найдёт сертификатов (см. раздел "Работа без HTTPS").

Запуск сервера
По умолчанию проект использует порты:
- HTTPS: 3006 (или значение переменной окружения `HTTPS_PORT` / `PORT`)
- HTTP (редирект на HTTPS): 3005 (или `HTTP_PORT`)

Запуск по умолчанию:

```powershell
npm run start
```

Запуск с указанием своих портов (PowerShell):

```powershell
$env:HTTPS_PORT = 3002; $env:HTTP_PORT = 3003; npm run start
```

Примеры доступа в браузере
- HTTPS: https://localhost:3006 (или ваш `HTTPS_PORT`)
- HTTP (редирект): http://localhost:3005 (или ваш `HTTP_PORT`)

Если сертификаты присутствуют и доверены в системе — сервис-воркер (`/sw.js`) сможет зарегистрироваться. Если сертификат не доверен, браузер выдаст ошибку регистрация SW (SecurityError).
